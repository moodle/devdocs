## General fixes and improvements {/* #general-fixes-and-improvements */}

{/* <!-- cspell:disable --> */}

- [MDL-89870](https://moodle.atlassian.net/browse/MDL-89870) - Install plugins page still offers installing from the plugins directory, which is no longer possible
- [MDL-89768](https://moodle.atlassian.net/browse/MDL-89768) - Respect the Wiki createpage capability in the mobile app
- [MDL-88910](https://moodle.atlassian.net/browse/MDL-88910) - filter_codehighlighter does not apply when rendered via JavaScript
- [MDL-88909](https://moodle.atlassian.net/browse/MDL-88909) - markdown_to_html should format codeblocks to match filter_codehighlighter
- [MDL-89868](https://moodle.atlassian.net/browse/MDL-89868) - Course index section links still point at the old positions after a section is moved
- [MDL-89820](https://moodle.atlassian.net/browse/MDL-89820) - LTI 1.3 content-item selection modal is too small for tools with substantial configuration UIs
- [MDL-89692](https://moodle.atlassian.net/browse/MDL-89692) - Calendar icon wraps onto its own line in date-time fields that have an "Enable" checkbox
- [MDL-89551](https://moodle.atlassian.net/browse/MDL-89551) - tiny_media accepts URLs without protocol but then crashes
- [MDL-89434](https://moodle.atlassian.net/browse/MDL-89434) - Fix multiple bugs in duration form element handling
- [MDL-89306](https://moodle.atlassian.net/browse/MDL-89306) - Changing date field on registration page, redirects to frontpage
- [MDL-89267](https://moodle.atlassian.net/browse/MDL-89267) - Restoring deleted question versions can split them across question bank entries
- [MDL-89250](https://moodle.atlassian.net/browse/MDL-89250) - Section collapse-all toggle can get stuck showing "Collapse all" when a subsection is left expanded
- [MDL-88803](https://moodle.atlassian.net/browse/MDL-88803) - Notification preferences do not show unconfigured message provider properly
- [MDL-87201](https://moodle.atlassian.net/browse/MDL-87201) - Remove subsections from the recycle bin
- [MDL-81898](https://moodle.atlassian.net/browse/MDL-81898) - The BigBlueButton plugin should provide set up recommendation when URL or secret is empty
{/* <!-- cspell:enable --> */}

{/* <!-- cspell:disable --> */}

- [MDL-89137](https://moodle.atlassian.net/browse/MDL-89137) - Router exception stack trace exposes internal directory structure when debugging enabled

## Security fixes {/* #security-fixes */}

A number of security related issues were resolved. Details of these issues will be released after a period of approximately one week to allow system administrators to safely update to the latest version.
