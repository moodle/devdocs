## General fixes and improvements {/* #general-fixes-and-improvements */}

{/* <!-- cspell:disable --> */}

- [MDL-90215](https://moodle.atlassian.net/browse/MDL-90215) - H5P packages do not work offline anymore (regression from [MSA-26-0044](https://moodle.org/mod/forum/discuss.php?d=482830#p1911925))
{/* <!-- cspell:enable --> */}

This fix is released in accordance with Moodle's [regression backporting policy](https://moodledev.io/general/development/policies/backporting#backport-fixes-to-unsupported-branches).

## Security fixes {/* #security-fixes */}

Security fixes are not applied to this version, as security support for 5.0.x ended on 5 October 2026. Sites using version 5.0.x are recommended to upgrade to a security supported version as soon as possible to ensure access to the latest security and other bug fixes.
