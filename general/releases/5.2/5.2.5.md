## General fixes and improvements {/* #general-fixes-and-improvements */}

{/* <!-- cspell:disable --> */}

- [MDL-90215](https://moodle.atlassian.net/browse/MDL-90215) - H5P packages do not work offline anymore (regression from [MSA-26-0044](https://moodle.org/mod/forum/discuss.php?d=482830#p1911925))
- [MDL-89461](https://moodle.atlassian.net/browse/MDL-89461) - Assignment with no grade and no feedback plugin fails with "Cannot load the grade item" for enrolled users
- [MDL-87486](https://moodle.atlassian.net/browse/MDL-87486) - Handle file uploads with filenames exceeding 255 characters gracefully
- [MDL-89905](https://moodle.atlassian.net/browse/MDL-89905) - Tasks which soft retry and run out of retries should turn into a task failure
- [MDL-89803](https://moodle.atlassian.net/browse/MDL-89803) - Wrong end date when unchecking Enable checkbox
- [MDL-87084](https://moodle.atlassian.net/browse/MDL-87084) - Activity completion override ignores passing grade
- [MDL-73856](https://moodle.atlassian.net/browse/MDL-73856) - Order of text filters not respected when changed in some subcontexts
- [MDL-90181](https://moodle.atlassian.net/browse/MDL-90181) - Opening a drawer between about 991px and 1005px width can leave the page unable to scroll
- [MDL-90012](https://moodle.atlassian.net/browse/MDL-90012) - Marking panel updates grade workflow state when grading is locked
- [MDL-89002](https://moodle.atlassian.net/browse/MDL-89002) - Glossary "Browse by alphabet" does not work for Cyrillic entries in Moodle 5.x
- [MDL-90205](https://moodle.atlassian.net/browse/MDL-90205) - Assignment quick grading can release grades without the required permissions
- [MDL-90134](https://moodle.atlassian.net/browse/MDL-90134) - Auto-create groups: Invisible system roles visible in "Select members with role" chooser if assigned to a user
- [MDL-90129](https://moodle.atlassian.net/browse/MDL-90129) - Empty activity badge shown next to the title of hidden or stealth Forum and File activities
- [MDL-89933](https://moodle.atlassian.net/browse/MDL-89933) - $CFG->nosmsever has no effect because should_send_sms() does not declare global $CFG
- [MDL-89925](https://moodle.atlassian.net/browse/MDL-89925) - The allow role assignments table lost the stripe layout from Moodle 4.5
- [MDL-89924](https://moodle.atlassian.net/browse/MDL-89924) - The manage roles table lost the stripe layout from Moodle 4.5
- [MDL-89915](https://moodle.atlassian.net/browse/MDL-89915) - Course heading missing from Live logs report
- [MDL-89891](https://moodle.atlassian.net/browse/MDL-89891) - Assignment: locked "Grant attempts", "Calculate grade" and "Rounding" defaults display no value
- [MDL-89667](https://moodle.atlassian.net/browse/MDL-89667) - Unix epoch timestamp appears in Activity Completion report tooltips
- [MDL-89492](https://moodle.atlassian.net/browse/MDL-89492) - TinyMCE plugins can modify other TinyMCE plugins' configurations
- [MDL-89248](https://moodle.atlassian.net/browse/MDL-89248) - Align the items in Dashboard better ("Recently accessed courses", "Course overview", and "Timeline" block)
- [MDL-84662](https://moodle.atlassian.net/browse/MDL-84662) - Event user_loggedout does not contain correct realuserid when "logged in as" another user
