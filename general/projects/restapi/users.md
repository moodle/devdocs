This work covers REST endpoints for managing Moodle user accounts, including listing, viewing, creating, updating, and deleting accounts, alongside password changes and recovery. User custom fields are still under analysis and will be added to this specification later. It is part of the [Moodle REST API project](https://tracker.moodle.org/browse/MDL-90030).

Explore the endpoint schemas in the **User Endpoints** section of the sidebar, or [download the OpenAPI specification](/projects/restapi/users/openapi.json).
